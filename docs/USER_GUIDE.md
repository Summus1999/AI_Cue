# AI_Cue 用户指南

> 读完这篇，你就能用好 AI_Cue。不用懂技术。

---

## 一、AI_Cue 是什么？

一句话：**面试时放在屏幕上的 AI 小助手。**

它做了什么好事：
- 面试官问问题，你打字或说话 → AI 马上给你参考答案
- 窗口不会被腾讯会议、Zoom 拍到（防捕获技术）
- 可以提前把你的简历、笔记、题目导进去 → AI 回答时参考你的资料
- 面试完帮你打分，告诉你哪里答得好、哪里需要补

---

## 二、怎么装？

### 你需要什么

- Windows 10 或 11 电脑
- 一个 AI 模型的 API Key（比如千问、DeepSeek、ChatGPT 的密钥）

### 安装步骤

1. 从发布页下载 `AI_Cue_Setup.exe`
2. 双击安装，一路点"下一步"
3. 安装完成后桌面会出现 AI_Cue 图标

---

## 三、第一次打开怎么设置？

打开软件后，会看到一个引导窗口，跟着它走就行：

### 第 1 步：配置 AI 模型

1. 点击右上角的 **齿轮图标**（设置）
2. 在「AI 模型设置」区域：
   - **提供商**：选你用的 AI（比如千问、DeepSeek、ChatGPT）
   - **模型**：选一个模型（比如 `qwen-plus`、`gpt-4o`）
   - **API Key**：把你买好的密钥填进去
   - **Base URL**：一般不用填，用默认的就行
3. 点「测试连接」看看能不能通
4. 通了就点「保存」

> 💡 **API Key 去哪搞？**
> - 千问：去 [dashscope.aliyun.com](https://dashscope.aliyun.com) 注册，点「API-KEY管理」
> - DeepSeek：去 [platform.deepseek.com](https://platform.deepseek.com) 注册，点「API Keys」
> - ChatGPT：去 [platform.openai.com](https://platform.openai.com) 注册，点「API Keys」

### 第 2 步（可选）：导入你的资料

如果你想让 AI 回答时参考你的笔记、简历、面经：

1. 打开设置 → 找到「RAG 检索与知识库」
2. 点「打开知识库」
3. 选一个知识库（如果没有，先用默认的）
4. 点「导入文档」，选你的 PDF、Markdown、文本文件
5. 等待状态变成「就绪（ready）」，就说明 AI 学完了

### 第 3 步：选模式

- **助手模式**：面试时用的，AI 帮你回答问题
- **面试官模式**：模拟面试，AI 扮演面试官考你

## 四、面试时怎么用？

### 基本操作

| 你想做的事 | 怎么做 |
| --- | --- |
| 问 AI 问题 | 在底部输入框打字，点发送按钮 |
| 用语音问 | 点麦克风按钮说话 |
| 截图让 AI 分析 | 点截图按钮，框选屏幕上的题目 |
| 让 AI 继续说 | 回答断了点「继续生成」 |
| 查看 AI 引用了哪些资料 | 看回答下面的引用标注 |

### 调整窗口

| 你想做的事 | 怎么做 |
| --- | --- |
| 让窗口更透明 | 拖动窗口右上角的透明度滑块 |
| 鼠标穿透窗口操作下面 | 按 Ctrl+Shift+P |
| 缩小成一条 | 按 Ctrl+Shift+C（紧凑模式） |
| 紧急隐藏 | 按 Ctrl+Shift+H |
| 把窗口拖到顺手的位置 | 直接拖标题栏 |

### 窗口为什么不会被拍到？

AI_Cue 用了 Windows 系统自带的「防捕获」能力。面试官的录屏软件（腾讯会议、Zoom 等）拍不到这个窗口，他看到的是你桌面原本的样子。

> ⚠️ **请注意**：有些公司可能要求共享整个屏幕而非单个窗口。这种情况下 AI_Cue 的防捕获仍然有效——窗口内容对其不可见。

## 五、记忆系统 — AI 越用越懂你

AI_Cue 会记住你的面试经历，让你越用越顺手：

### 它是怎么记住的？

- 每次 AI 回答完，会自动抽取出你关心哪些知识点、怎么回答的
- 相同的信息不会重复记录
- 太久没用的记忆会自动归档
- 记多了会自动总结出你的特点（比如「你擅长算法题」「你喜欢用 Python」）

### 你想自己管理记忆？

打开设置 → 点「记忆管理」：

- 可以浏览 AI 帮你记的所有东西
- 可以删除不需要的记忆
- 可以修改记忆内容
- 点「运行维护」让 AI 立刻整理一遍

## 六、面试完了做什么？

### 看复盘报告

面试结束后：

1. 点「复盘」按钮
2. AI 会从五个维度打分：
   - 自信度
   - 专业度
   - 技术深度
   - 理论与实际结合
   - 技术敏感度
3. 告诉你哪里答得不好、建议怎么改进
4. 可以导出 PDF 保存

### 对比进步

如果你用了很多次，可以在复盘页面看「趋势对比」——一条曲线告诉你最近是进步了还是退步了。

## 七、更多功能

### 智能路由 — 一个模型挂了自动换另一个

在设置里配置多个备选模型（比如千问 + DeepSeek），设置优先级。AI_Cue 会自动检查哪个能用，选最快的。如果当前模型挂了，自动切换。

> 📖 适合有多个 API Key 的用户，保证面试关键时刻不掉链子。

### 答题模式

在 Prompt 设置里选「答题模式」，AI 会切换到更精炼的回答风格——不解释、不啰嗦，直接给答案。

### TTS 朗读

点 AI 回答旁边的喇叭图标，AI_Cue 会用电脑语音把答案读出来。面试时不方便看屏幕的时候特别有用。

### 导出对话

可以把整场面试的对话导出为 Markdown 或 PDF，方便之后复习。

## 九、常见问题

### Q：AI 回答很慢怎么办？
- 检查网络
- 换一个更快的模型（比如 qwen-turbo）
- 在设置里关掉 RAG 检索，减少查资料的时间

### Q：窗口被拍到了怎么办？
- 检查设置里是否开启了「自动隐身检测」
- 按 Ctrl+Shift+H 紧急隐藏

### Q：导入的 PDF 识别不了？
- 确认打开了 OCR 开关（在设置→RAG 里）
- 删除后重新导入一次，确保 OCR 生效

### Q：API Key 在哪填？
- 设置 → AI 模型设置 → API Key

### Q：怎么删除聊天记录？
- 左侧或顶部有会话列表，点垃圾桶图标删除
